# Peggle: Dual Shot on ReRead (experimental)

A small, standalone ReRead launcher using the Debian i386 **DeSmuME CLI**
emulator. This does not use Wine, Steam or the previous Peggle retail importer.
It **does not include a Nintendo DS ROM**. The user supplies their own
`Peggle: Dual Shot` `.nds` file.

## Build (same workflow as Booru)

From the ReRead checkout:

```sh
docker run --rm -v "$PWD:/work:z" reread-builder python3 /work/antix/apps/peggle-ds/package.py
```

Result: `out/antix/reread-app-peggle-ds_0.1.0_i386.deb`.
The package uses the existing system Debian `desmume` package as its only
emulator dependency. Its executable is only a few megabytes installed, not
hundreds of megabytes like Wine. No system/USB installer rebuild is needed.

## Run

1. Install the package via ReRead's web **Apps** page or Software.
2. Upload an owner-supplied `.nds` ROM to **Files** (ideally `Games/`).
3. Launch **Peggle DS** from ReRead Home.
4. Press OK to play. The app starts `desmume-cli` with a horizontal DS
   screen layout and no emulated 3D renderer. Press Favorites to quit back.
   Save data generated by DeSmuME follows the emulator's normal ROM/save
   behavior. Do not delete your ROM if you want to preserve its save files.

ReRead uses a tiny app-local SDL2 interposer while the game runs. It selects
software SDL window rendering, since the Intel Poulsbo graphics may not support
modern accelerated SDL2. It also converts the physical buttons into DeSmuME's
keyboard defaults. This does not change XKB globally or touch system input.

| Reader control | DS action |
|---|---|
| D-pad | D-pad |
| OK | A |
| Back | B |
| Options | Start |
| Play | Y |
| Zoom minus | L |
| Zoom plus | R |
| View | Select |
| Favorites | Quit game |

Power, Hold and hardware volume remain system-owned. The app launcher uses
ReRead's shared UI/Guide handling. The emulator is a separate SDL window and
does not yet render ReRead's Guide overlay while playing.

## Test status and limitations

**Not yet tested on actual Reader hardware.** DeSmuME's CPU emulation may be
too slow for the Intel Atom Z520 even though its disk footprint is small.
The bundled adapter forces an SDL software renderer, but success and frame
rate must be established on the Reader. Some DS game menus may expect stylus
input; the Peggle: Dual Shot gameplay itself supports controller aiming.
This is a first hardware-test build, not a demonstrated fully playable port.

No ROM download is implemented. No ROM or proprietary Nintendo files are
bundled or distributed by this project.
